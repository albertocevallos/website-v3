### Challenge

I often found myself googling online converters for BigNumbers or Keccak256 whenever working on a smart contract.
These tools are spread all over the web and are inconvenient to track.

### Solution

I interviewed a handful of Typescript/Solidity devs and found they frequently searched for:

- [Unit converters](https://eth-converter.com/)
- [Checksum](https://ethsum.netlify.app/)
- [Hexstring converters](https://www.rapidtables.com/convert/number/hex-to-decimal.html)
- [keccak256 converters](https://emn178.github.io/online-tools/keccak_256.html)

I went ahead and built a website using [Vercel](https://vercel.com/) and [Next.js](https://nextjs.org/) and implemented an initial list of utils using [ethers.js](https://docs.ethers.io/v5/).

### Results

[eth-utils.com](https://eth-utils.com) currently supports 4 utilities. The source code is available on [GitHub](https://github.com/albertocevallos/ethutils), feel free to create an issue if you'd like to see any new feature.
