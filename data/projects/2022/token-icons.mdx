### Challenge

In Web3, whenever you build a frontend, you go through the following process:

1. Source ERC-20 icons (you'll usually find them on Google)
2. If you you use AWS, then you store them on an [AWS S3 bucket](https://aws.amazon.com/s3/)
3. And then host them on [Route 53](https://aws.amazon.com/route53/)

If you're managing more than one frontend, this can get quite expensive. I believe the costs of storing and retrieving these assets could be socialized amongst devs.

### Solution

Inspired by [github.com/trustwallet/assets](https://github.com/trustwallet/assets), I decided to build a repository of ERC-20 assets on top of GitHub. The problem with the current Trust Wallet implementation is that their tokens are no longer up-to-date, and mostly from the ICO era.

I started off by collecting common ERC-20 icons I use in DeFi frontends and hosted them [here](https://github.com/albertocevallos/token-icons/tree/main/assets). I then setup a basic [Vercel website](https://vercel.com/) to let devs visually navigate through the collection.

```tsx
import { image } from 'token-icons'

const Example = () => {

    return (
        <img src={image('0xFd086bC7CD5C481DCC9C85ebE478A1C0b69FCbb9')} />
    );
  }
}
```

### Results

I launched [tokenicons.org](https://tokenicons.org/) in late October 2022 and deployed a simple [NPM package](https://www.npmjs.com/package/token-icons) that you can use in your React app. As always, you can find the code for the project [here](https://github.com/albertocevallos/token-icons).
